### 実験1: なぜ √d_k で割るのか
```text
実験1: なぜ sqrt(d_k) で割るのか ― 内積の分散を実測
==============================================================

QとKの各成分が平均0・分散1のとき、内積 q・k = Σ q_i*k_i の分散は
理論上 d_k になる（独立な項の和の分散は項数に比例）。
これを実際にサンプリングして確かめる。

    次元 d_k         内積の分散(実測)        sqrt(d_k)で割った後
         4              4.01                 1.003
        16             15.79                 0.987
        64             64.19                 1.003
       256            257.88                 1.007
      1024           1038.62                 1.014

→ 内積の分散は d_k とほぼ一致（理論通り）。
  sqrt(d_k)で割ると、どの次元でも分散≈1に正規化される。

==============================================================
```

内積の分散が次元 d_k に比例して増大し（d_k=64 → 分散 64.2）、
√d_k で割ると分散≈1 に正規化されることを実測。これが Attention のスケーリングの理由。

### 実験4: 残差接続と LayerNorm の役割分担
```text
実験4: 残差接続(residual)とLayerNormが深いネットを安定させる
==============================================================

Transformerは何十層も積む。層を深くすると、信号(activation)が
指数的に増大/減衰しやすい。残差接続とLayerNormがこれを防ぐ。
各層での信号の大きさが、深さとともにどう変化するかを追う。

構成                                             1層目      10層目      25層目      50層目
--------------------------------------------------------------------------------
残差なし・Normなし                                0.679     0.784     0.692     0.739
残差あり・Normなし                                1.050     2.390     4.972     5.300
残差あり・Normあり(=Transformer)                  0.802     0.827     0.784     0.751

→ 各構成での信号の推移:
  ・残差なし・Normなし → tanh飽和で信号がほぼ一定の小さい値に潰れる
    (層を重ねても情報が育たず、深くする意味が薄れる)
  ・残差あり・Normなし → 信号が層ごとに積み上がり、どんどん増大
    (放置すると爆発。だから正規化が要る)
  ・残差あり・Normあり → 信号が一定の健全な範囲に保たれる
    これが『Transformerを何十層も安定して積める』理由。
```

残差接続は「信号を奥まで届ける」、LayerNorm は「大きさを整える」という役割分担が
数値で見える。これが Transformer を何十層も安定して積める理由。
