# Day6: ファインチューニング (SFT / LoRA)

事前学習だけでは指示に従えないモデルを、SFT（Instruction Tuning）で質問応答できるようにし、
LoRA で「わずかなパラメータ更新だけで効率よく鍛える」仕組みを実装・検証する。

---

## 基礎編 `day6_sft_lora.py`

事前学習だけのモデル → SFT → LoRA の3段階を比較する。

```bash
python day6/day6_sft_lora.py
```

**実行結果（要約）:**
```text
Using device: cuda
語彙サイズ(特殊トークン込み): 92

総パラメータ数: 230,364

=== ステップ1: 事前学習（次の単語予測のみ） ===
step    0 | pretrain loss 4.680
step  100 | pretrain loss 0.049
```

事前学習だけでは支離滅裂だった応答が SFT で的確になり、
**LoRA は全体の 7.11% のパラメータ更新だけで Full-FT と同じ精度**を達成している。

### 実験1: B のゼロ初期化で学習開始時 ΔW=0
```text
実験1: Bゼロ初期化により、学習開始時の増分ΔWがゼロであることを確認
```

### 実験2 & 実験3: ランク r のトレードオフと重みマージ
```text
実験2: LoRAのランク r を変えて、性能とパラメータ数のトレードオフを見る
============================================================
r= 1 | 学習パラメータ   4,096 | SFT loss 0.159 | 簡易正答率 1.00
r= 2 | 学習パラメータ   8,192 | SFT loss 0.155 | 簡易正答率 1.00
r= 4 | 学習パラメータ  16,384 | SFT loss 0.150 | 簡易正答率 1.00
r= 8 | 学習パラメータ  32,768 | SFT loss 0.150 | 簡易正答率 1.00
r=16 | 学習パラメータ  65,536 | SFT loss 0.155 | 簡易正答率 1.00

→ rを上げると表現力(学習パラメータ)は増えるが、簡単なタスクでは
  小さいrでも十分。実務では『必要最小限のr』を探すのが定石。

============================================================
実験3: 推論時マージ ― ΔWをbaseに足すとLoRA層が不要になる（高速化）
============================================================
マージ前後の出力の最大差: 2.86e-06
→ ほぼゼロ（数値誤差レベル）。マージしても出力は同一。
  マージ後はΔW計算(x@A@B)が消え、通常のLinearと同じ計算量で推論できる。
  これがLoRAの『推論オーバーヘッドなし』という最大の実務的利点。
```

学習後に ΔW を元の重みへマージすると出力が一致（誤差 ~1e-6）し、
**推論オーバーヘッドがゼロ**になる。これが LoRA が実務で主流になった決定的理由。
